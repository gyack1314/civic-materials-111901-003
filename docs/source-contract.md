# 本地来源契约

门户为合成 ESG 申请站。运行后打开首页，企业 C01 与 C02 显示同名但代码与范围不同，年度选择后上下文卡片延迟显示就绪。操作只通过页面控件及页面下载进行，页面请求属于门户实现，不是对外批量接口。
页面显示申请号、企业代码、年度、范围、处理状态、原件册别与额度已使用数量。每次受理会产生一个申请并消耗一次额度，无幂等键；演练阶段 1 在受理后断开响应且延迟两秒来源时间显示申请，阶段 2 标记手工申请，阶段 3 令补充册暂不可用。申请三秒来源时间后可下载，各下载地址四秒后过期，可以在同一申请刷新领取地址。原件内声明申请与册别。
演练时钟与控制入口只供操作员调整来源情形，不用于读取或判断待采集数据。页面有申请列表刷新和重新领取下载地址按钮，关闭再打开页面不会删除已受理申请。

演练来源由 Python 标准库 HTTP 服务启动，默认端口 8765。GET /health 可查询来源时间与阶段；POST /__admin/advance 接收 seconds、phase 推进本地情形；GET /__admin/log 回查实际请求。这些控制只供操作员调试来源，不能替代产品从正常入口取得资料。来源进程重启会清空其演练状态；采集端自己的保存目录由产品独立管理。
